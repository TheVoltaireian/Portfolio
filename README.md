# Website
A work-in-progress portfolio/blog website that I'm working on

- <b>Portfolio:</b> List of wikis and projects I've worked on in the past few years
- <b>Blog:</b> A page where I'll occasionally write about things that have happened in my life

## Technical Details 🖥️
- Visual Studio Code
- HTML, Sass (autocompiled to CSS using the Watch Sass VSCode extension) & JavaScript
- Bash
- Git
- GitHub Pages

## Roadmap 🌴
- Split variables.scss into multiple files
  - breakpoints.scss (for media queries), tokens.scss (scss variables), variables.scss (:root variables)  
- Add more links to footer
- Set up portfolio carousel
- Transition to self-hosting fonts
  - Find a good-looking mono font
- Add ARIA labels
- Transition from buttons to links
- Purchase a domain
- Revamp the page file structure to make links more navigable
- Create a navbar component
- Set up an issues template for future usage
